# Fundamentals-of-C-Programming-and-Logical-Operations

#FAST National University - Programming Fundamentals (PF) Lab Assignment:

#Implementation of Mathematical Operations and Logical Concepts Using C Programming

This repositories consists of four C programming tasks designed to demonstrate fundamental programming concepts, mathematical operations, logical reasoning, and problem-solving techniques.

1.Divisibility Counter and Range Analyzer: Counts numbers divisible by 3 and 5 within a given range and calculates their ratio.
2.Fibonacci Series Generator: Generates the Fibonacci series up to 10,000 and calculates the sum of terms divisible by 3, 5, or 7.
3.GCD and LCM Calculator: Calculates the Greatest Common Divisor (GCD) and Least Common Multiple (LCM) of two integers.
4.Number-to-Word and Even-Odd Classifier: Converts numbers from 1 to 9 into words and classifies other numbers as even or odd.

#How to Run the Code

gcc task1.c -o task1
./task1
